# JW → Hybrid Peptide Program Conversion System

## Purpose
Design a systematic, repeatable method to convert JW-style short-iteration peptide programs into structured hybrid long-dwell peptide programs, optimized primarily for **Spooky2 Remote**, long-duration runtime (overnight → 24/7), and single-generator deployment initially.

This document defines the architecture, logic rules, timing conversions, and implementation framework for building a universal conversion tool with optional advanced evolution.

---

# 1. Core Paradigm Shift

## JW Model (Looped Fragment Signalling)
- Very short dwell (1–4 sec typical)
- High repetition density
- Fragmented peptide chain delivery
- Continuous looping
- Informational nudging

## Hybrid Model (Staged Assembly & Locking)
- Structured phases
- Weighted dwell by importance
- Assembly/ignition step
- Long peptide anchor dwell
- Synergist stabilization

Conversion is NOT time scaling.
It is a change from:

**Repetition signalling → staged biological instruction architecture**

Optimized for long-duration Remote transmission.

# 4. Repetition Density → Dwell Conversion

JW repetition count becomes biological priority signal.

| Occurrence in JW chain | Hybrid dwell assignment |
|------------------------|------------------------|
| Very high frequency | 50–70 sec |
| Medium frequency | 25–45 sec |
| Low frequency | 10–20 sec |

Formula option:

```
dwell_seconds = 8 + (occurrence_count × 3–5)
max = 75 sec
```

This preserves JW weighting without loop repetition.
